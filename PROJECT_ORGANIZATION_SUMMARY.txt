🚀 QUICK START - PUSHING TO GITHUB
═══════════════════════════════════════════════════════════════════════════════

1. CREATE EMPTY REPOSITORY
   • Go to https://github.com/new
   • Name: academy-website
   • Leave empty (no README, no .gitignore)
   • Click Create Repository

2. INITIALIZE & PUSH
   
   cd /path/to/Academy_website
   
   git init
   git add .
   git commit -m "Initial commit: NodalWire Academy website"
   git branch -M main
   git remote add origin https://github.com/nodalwire/academy-website.git
   git push -u origin main

3. VERIFY ON GITHUB
   • Visit https://github.com/nodalwire/academy-website
   • All 9 pages should be visible in public/
   • Check: no node_modules folder
   • Check: all assets present

4. CONFIGURE GITHUB
   • Add description: "Educational platform for network engineering training"
   • Add topics: education, networking, courses, website, telecommunications
   • Enable GitHub Pages (optional)
   • Set custom domain (optional)
